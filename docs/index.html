Behind the numbers +

One race. All 20 horses.

The entire project uses the 2024 Kentucky Derby at Churchill Downs in Louisville, Kentucky, USA, on May 4, 2024. The source contains all 20 starters, final odds, official finish positions, and positions at six checkpoints. Scratched horses did not start and are excluded.

The animated hero is a decorative track model, not a scale map of Churchill Downs. The replay uses recorded ranks; movement between checkpoints is illustrative, not measured speed or gaps.

From odds to a chance

US odds-to-one describe profit on a $1 bet. Add 1 to include the original stake: 18.61-to-1 becomes 19.61. Raw implied chance = 1 / 19.61. We divide each raw chance by the field’s total so adjusted chances add to 100%.

Odds rank 1 is the lowest price. Official finish 1 is the winner. A $2 win bet returns 2 × (odds + 1) only if the horse wins; otherwise it returns $0. These are final tote odds, not a guaranteed price available earlier.

What one race cannot tell us

There is no multi-race calibration curve, fitted regression, or estimated long-run return here. All outcome comparisons are descriptive. One win does not prove a good bet, and one loss does not prove a bad probability.

Horse names may include a breeding-country suffix. Every observation in this project is from a race run in the USA.
